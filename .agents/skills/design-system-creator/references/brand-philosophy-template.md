# Brand Philosophy Specification Template

This template outlines the structure for `BRAND_PHILOSOPHY.md` generated by the `design-system-creator` skill.

```markdown
# Brand Philosophy

## Overview & Mission
[Summary of the product's purpose, core promise, and primary utility]

## Brand Personality
[3-5 core personality traits described in human terms]
- **[Trait 1]**: [Explanation of what this means for product identity]
- **[Trait 2]**: [Explanation]
- **[Trait 3]**: [Explanation]

### Personality Anti-Patterns (Avoid)
- **[Avoid 1]**: [e.g., Playful / Gamified - because it distracts from focused utility]
- **[Avoid 2]**: [e.g., Corporate / Cold]
- **[Avoid 3]**: [e.g., Overly Futuristic / Sci-fi]

## Voice & Tone
- **Primary Voice**: [Clear, precise, direct, empathetic, technical, etc.]
- **Copywriting Principles**:
  1. [Principle 1, e.g. Focus on user clarity over marketing hype]
  2. [Principle 2, e.g. "Understand yourself better" instead of "Optimize harder"]
- **Microcopy Style**: [Button labels, error messages, empty states tone]

## Target User & Emotional Direction
- **Target User Persona**: [Who is using this product and in what context]
- **Emotional Goal**: [How the user should feel during and after interaction: calm, confident, empowered, focused]

## Visual References & Anti-Trophies
- **Inspired By**: [Reference sites, products, or aesthetics]
- **Forbidden Cliché Tropes**:
  - [Forbidden trope 1, e.g., Purple/violet accents on dark backgrounds]
  - [Forbidden trope 2, e.g., Icon-stuffed bento boxes with unrelated icons]
  - [Forbidden trope 3, e.g., Headline biscuit pills with pulsing dots]

## Do's and Don'ts
### Do:
- Align visual hierarchy with cognitive priority.
- Keep copywriting concise, respectful, and intentional.
- Maintain consistent visual tone across all touchpoints.

### Don't:
- Introduce gamification badges, streaks, or confetti unless explicitly directed.
- Use artificial urgency or pushy marketing language.
```
